TV Series Assistant е конзолно Python приложение за управление на любими сериали, проследяване на прогреса и получаване на интелигентни AI препоръки според това какво гледаш.
Проектът е разработен с учебна и практическа цел от студент в ТУ–София, като комбинира чист софтуерен дизайн, работа с файлове (JSON) и основна AI логика.

Основни функционалности:
   Добавяне на нови сериали,
   Преглед на всички сериали,  
   Обновяване на гледаните епизоди,
   Изтриване на сериал,
   Търсене по име,
   Статистика за цялата колекция,
   Препоръки за сериали според гледаните жанрове,
   Автоматично записване и зареждане на данни (JSON),
Използвани технологии:
  Python 3,
  Object-Oriented Programming (OOP),
  JSON file storage,
  Basic AI / Recommendation logic,
Учебна стойност:
Проектът помага за усвояване на:
  Структуриран код и разделяне на отговорности,
  Работа с файлове,
  Моделиране на данни,
  Базови AI концепции,
  Добри практики за GitHub проекти
Идеи за бъдещо развитие:
   GUI (Tkinter / PyQt / Web app),
   Интеграция с IMDb / TMDb API,
   Machine Learning препоръки,
   Потребителски профили,
   Чат асистент за избор на сериал,
Автор:
